Modelo de gravedad del comercio de México (2023)

Author

BERNARDINO MUÑOZ KARLA VERÓNICA - VIURQUIS NAVA DULCE MARÍA - VIURQUIZ ANDRADE DANTE EMILIANO

Este documento contiene el código en R utilizado para estimar un modelo de gravedad de las exportaciones de México hacia 115 países en 2023. Las variables explicativas son el PIB del país socio, la distancia, la existencia de un TLC, el idioma común y el Índice de Desempeño Logístico (LPI). Fuentes: WITS, Banco Mundial y CEPII.

6.1 VIF FACTOR DE INFLACIÓN DE LA VARIANZA

Ver código 
# ---- 6.1 FACTOR DE INFLACIÓN DE LA VARIANZA (VIF) ----
# Para cada variable explicativa: se hace una regresión contra las demás,
# se toma su R2 y se calcula VIF = 1 / (1 - R2).
# Regla: VIF > 10 indica multicolinealidad grave.
variables <- c("ln_pib", "ln_dist", "tlc", "idioma", "ln_lpi")

vif <- sapply(variables, function(v) {
  otras <- setdiff(variables, v)
  r2 <- summary(lm(reformulate(otras, v), data = datos))$r.squared
  1 / (1 - r2)
})

8. Prueba t

PRUEBA DE ELASTICIDAD DEL PIB = 1

Ver código 
# ---- 8. PRUEBA t: ¿LA ELASTICIDAD DEL PIB ES IGUAL A 1? ----
# H0: b_pib = 1 (las exportaciones crecen igual que el PIB del socio)
# H1: b_pib distinto de 1
b_pib  <- coef(modelo)["ln_pib"]
ee_pib <- summary(modelo)$coefficients["ln_pib", "Std. Error"]

t_pib <- (b_pib - 1) / ee_pib
p_pib <- 2 * pt(abs(t_pib), df = modelo$df.residual, lower.tail = FALSE)
